
# Lotto Number Generator

## Overview

This application generates a set of 6 unique random numbers between 1 and 45, simulating a lottery draw.

## Features

*   **Number Generation:** Generates 6 unique random numbers.
*   **Display:** Shows the generated numbers in a clear and visually appealing way.
*   **User Interface:** A simple and intuitive interface with a button to generate the numbers.
